    How the model works, and what it does not do
    • Dead time. t0 = 0.65 × V_column / F. Retention time tR = t0 (1 + k). Flow changes t0 and tR, not k.
    • Organic strength. log k = log kw + Δ − S·φ, with separate kw and S for ACN and MeOH per analyte, so the two solvents can reorder peaks. [Certain] form; parameters invented
    • Stationary phase. Shorter alkyl chains retain less: log kw is scaled by 0.86 (C8) and 0.74 (C4), and S by 0.94 and 0.88. Hydrophobic analytes lose more retention than polar ones, so selectivity shifts a little. Silanol effects on bases and efficiency differences between phases are not modelled. [Likely] trend; [Guessing] magnitudes
    • Temperature. van't Hoff with Q = 11–14 kJ/mol, about 1.4 % less k per °C near 30 °C. Selectivity can drift because Q differs per analyte. [Likely]
    • pH. Fast ionisation equilibrium: k = kN (fN + 0.05 (1 − fN)), so the ionised form is 20× less retained. Apparent pKa moves +0.012 per % B for acids and −0.004 for bases. [Likely] direction; [Guessing] magnitudes
    • Efficiency. H = (dp/5)(6 + 3/f + 3f) µm, f = F (dp/5) / (ID/4.6)². Written in reduced terms (h = H/dp, ν ∝ u·dp), so F_opt ∝ 1/dp and H at the optimum ∝ dp. N = L / H. Peaks are Gaussian, σ = tR / √N. [Likely] dp scaling; [Guessing] coefficients
    • Area and height. Area ∝ 1/F (concentration detector). Height ∝ 1/σ, so it falls as k rises in isocratic mode.
    • Pressure. Kozeny–Carman, ΔP ∝ 1/dp², mixture viscosity from a Grunberg–Nissan fit, ×1.6 for hardware. Limit assumed 400 bar for dp ≥ 3 µm and 1000 bar below. Order of magnitude only. [Certain] 1/dp²; [Guessing] absolute values and limits
    • Not modelled: gradients, THF, extra-column volume (so N for sub-3 µm is optimistic), viscous heating, peak tailing, buffer strength, temperature effect on pKa, mixing of overlapping peaks beyond simple addition.
